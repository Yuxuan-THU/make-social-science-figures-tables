# APSR profile

## Authority order

1. Explicit user or submission instructions.
2. Current APSR/Cambridge instructions and APSA style requirements.
3. Recurring production patterns in the local published-sample corpus.
4. Author-specific choices, used only when they improve the particular artifact.

## Figures

- Heading: `FIGURE n.` plus a short title in headline-style capitalization.
- Use a supplied manuscript number when one exists. If numbering is not supplied, do not invent a claim about manuscript order: use an explicit placeholder such as `FIGURE X.` or a clearly documented standalone-demo number.
- Default typography: compact sans serif (`sans`, normally Arial/Helvetica/Noto Sans), black text, consistent size across panels. Published samples mix fonts; portability matters more than imitating a proprietary face.
- Default background: white. Use restrained light-gray reference/grid lines only when they help comparison; never rely on grid color to carry meaning.
- Use black baselines and direct reference lines; distinguish zero lines from confidence intervals.
- Preserve black-and-white interpretation with line type, shape, or pattern in addition to color.
- Put keys inside the figure or caption; explain every symbol and pattern.
- Number panels `(a)`, `(b)`, etc. in reading order. State when scales differ.
- Recommended full-width size: 6.5 in wide. Start at 4.4–5.2 in high; expand tall plots instead of shrinking labels below 7 pt.

## Tables

- Heading: `TABLE n.` plus a headline-style title. Row and column labels use sentence-style capitalization.
- Use three principal horizontal rules (`booktabs`) and no vertical rules. Add partial rules only for grouped headers.
- Put coefficients on one line and standard errors immediately below in parentheses.
- Align numeric columns at decimal points and use one precision within a comparable block.
- Note order: general explanatory note; specific/superscript notes; source/credit if needed; significance legend last.
- Default significance legend follows the manuscript evidence. Do not invent cutoffs or silently change symbols.
- Tables must be interpretable without running text and should avoid extreme width.

## Accessibility and provenance

- Title/caption must convey measure, comparison, unit, and uncertainty definition where relevant.
- Use `Source:` for unoriginal material and preserve permission wording.
- APSR reproducibility packages must make every published artifact locatable in code and output. QA must therefore include source script, data slice, and output path.

## Derived vs official

Headline capitalization, Arabic numbering, chronological order, self-contained notes, source credit, and black-and-white viewability are official APSA guidance. Font family, dimensions, line weights, and restrained gray references are corpus-derived defaults, not mandates.
